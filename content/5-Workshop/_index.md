# Workshop: CloudMenu on AWS

This workshop provides an in-depth overview of the CloudMenu AWS system architecture, including the AWS services used, the request flow between the frontend and backend, the Serverless architecture, and access control mechanisms.

The architecture and deployment of CloudMenu are presented by component, including Amazon S3 and Amazon CloudFront for frontend hosting and content distribution, Amazon API Gateway and AWS Lambda for backend processing using a Serverless architecture, Amazon DynamoDB for storing order data, and AWS IAM for managing access permissions and system security.

The workshop also covers the order workflow, frontend deployment, API processing, DynamoDB data model, IAM permissions, and Lambda monitoring. These topics help illustrate how the AWS services work together to support and operate the CloudMenu system.

Content is grouped into the following main sections for easier navigation:
- Overview and System Architecture of CloudMenu
- AWS Services and Security Mechanisms
- Serverless System Deployment and Operations
- Cost, Risks, and Expansion Roadmap
- AWS Resource Cleanup and Management
