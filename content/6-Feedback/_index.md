### Overall Evaluation

**1. Working Environment**  
The working environment was supportive, comfortable, and easy to adapt to. Everyone was willing to help whenever I encountered technical issues — especially with AWS service configuration, Lambda debugging, or CI/CD pipeline troubleshooting. The flexible and remote-friendly environment fit well with my schedule. I think the program could add more team-sharing sessions or bonding activities to strengthen connections among interns.

**2. Support from Mentor / Team Admin**  
The mentor provided very detailed guidance, especially on deploying systems on AWS, including using Amazon S3 and Amazon CloudFront for content storage and distribution, as well as integrating Amazon API Gateway, AWS Lambda, and Amazon DynamoDB to build a serverless backend. The mentor also guided me on using AWS IAM to manage access permissions and system security. Instead of providing the answers directly, the mentor encouraged me to analyze problems, identify their causes, and find solutions on my own — which I highly appreciated. The admin team was also very supportive, providing helpful documentation, clear processes, and prompt assistance whenever I had questions.

**3. Relevance of Work to Academic Major**  
The tasks, such as deploying a serverless architecture on AWS, using Amazon S3 and Amazon CloudFront for content storage and distribution, integrating Amazon API Gateway, AWS Lambda, and Amazon DynamoDB to build the backend, and using AWS IAM to manage access permissions and system security, were well aligned with the knowledge I had acquired. The internship helped me gain a better understanding of how AWS services can be integrated into a real-world system and gave me the opportunity to apply theoretical knowledge from my studies to the deployment and operation of a system in a cloud environment.

**4. Learning & Skill Development Opportunities**  
The internship allowed me to gain valuable hands-on skills, including:

- Gained a better understanding of serverless architecture on AWS, particularly how Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, and Amazon DynamoDB work together.
- Learned how to deploy and distribute content using Amazon S3 and Amazon CloudFront.
- Learned how to build a backend using a serverless architecture with Amazon API Gateway, AWS Lambda, and Amazon DynamoDB.
- Improved my knowledge of access management and system security through AWS IAM.
- Developed skills in analyzing system architecture and understanding how AWS services connect and work together in a real-world system.
- Improved my technical documentation skills and learned how to clearly present system components and workflows.

Soft skills such as teamwork, progress reporting, communication, and handling issues professionally also improved significantly throughout the program.

**5. Company Culture & Team Spirit**  
The team culture was positive and respectful. Everyone worked seriously but was still friendly and supportive. Even during busy periods, team members helped each other without hesitation. This made me feel like I was part of the team, not just an intern.

**6. Internship Policies / Benefits**  
The program provided flexibility in working hours and gave access to useful learning materials. The opportunity to work on an end-to-end real project — from architecture design to AWS production deployment with monitoring — was one of the biggest benefits, helping me build practical experience beyond what is taught academically.

### Additional Questions

- **What was I most satisfied with during the internship?**  
  I had the opportunity to build and deploy a serverless system on AWS, from designing the architecture and managing content storage and distribution with Amazon S3 and Amazon CloudFront to building the backend using Amazon API Gateway, AWS Lambda, and Amazon DynamoDB. In addition, I gained hands-on experience with access management and system security through AWS IAM. This practical experience helped me gain a deeper understanding of how to build and deploy a cloud-native system on AWS, an area I had not had many opportunities to explore in depth before.

- **What should the program improve for future interns?**  
  It would be beneficial to include more focused technical workshops (e.g., deeper serverless patterns, advanced AWS security configurations, container orchestration) or scheduled study sessions.

- **Would I recommend this internship to others? Why?**  
  Yes. Because the program offers real project experience, strong mentorship, and practical skill development that directly benefit career growth.

- Introduce periodic demo sessions or sprint reviews so interns can learn from each other's progress.
