During my internship at AMAZON WEB SERVICES VIETNAM COMPANY LIMITED from June 22, 2026, to August 15, 2026, I had the opportunity to participate in the real-world project “CloudMenu AWS” — an online table ordering system built using a Serverless architecture on the Amazon Web Services (AWS) platform.

During the internship, I applied the knowledge I had acquired at university, including software engineering, database systems, and cloud computing, to participate in developing the online ordering system. The system allows customers to scan a QR code at each table to view the menu, select items, and place orders. Requests are processed through Amazon API Gateway and AWS Lambda, while order data is stored in Amazon DynamoDB. In addition, the system provides a dedicated interface for kitchen staff to receive orders and update their preparation status, as well as a Dashboard that allows Admins/Managers to monitor order statistics and revenue.

I contributed to the development of key modules in the system, including:

- Designed and implemented the table ordering system using a Serverless architecture on AWS, utilizing Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, and Amazon DynamoDB.

- Developed core system functionalities, including displaying the menu through table-specific QR codes, selecting menu items, creating orders, and submitting orders.

- Built the serverless backend using Amazon API Gateway and AWS Lambda to process requests from customers and staff, while storing and retrieving order data through Amazon DynamoDB.

- Developed a dedicated interface for kitchen staff to receive customer orders and update their preparation status.

- Developed a statistical Dashboard for Admins/Managers to monitor the total number of orders, revenue, order status, revenue by table, and the most frequently ordered items.

- Used AWS IAM to manage access permissions and ensure that AWS resources were properly secured and authorized.

- Supported system architecture analysis, documented the interactions and workflows between system components, and contributed to the technical documentation.

Beyond technical skills, I developed communication, teamwork, documentation, and problem-solving abilities by working closely with supervisors and adapting to professional workflows.
